# DanceStart — сайт танцевального клуба

Учебный проект по дисциплине «Фронтенд и Бэкенд разработка».
Сайт танцевального клуба DanceStart: информация о клубе и тренерах,
расписание занятий с фильтрами, запись на индивидуальные тренировки,
отзывы и популярные вопросы.

## Технологии

- HTML5
- CSS3 (Grid, Flexbox, CSS-переменные)
- JavaScript

## Структура

- `index.html` — главная страница: о клубе, фотогалерея, 8 тренеров
- `schedule.html` — расписание на неделю с фильтрами по тренировке, тренеру, дню, времени
- `booking.html` — запись на индивидуальную тренировку через модальное окно
- `reviews.html` — отзывы и FAQ (аккордеон)
- `css/style.css` — единый файл стилей
- `js/` — скрипты страниц
